Markdown 编辑器

一个现代化的 Markdown 编辑器，支持实时预览、文档管理、代码高亮、数学公式和图表渲染。 同时支持 Web 应用和桌面应用。

主要技术栈

Vite 7 下一代前端构建工具，提供极速的 HMR 和优化的生产构建 Marked 17 高性能 Markdown 解析器，支持 GitHub 风格 Markdown 扩展 CodeMirror 6 模块化文本编辑器框架，提供语法高亮和丰富的扩展能力 Monaco Editor VS Code 底层编辑器组件，支持 IntelliSense 和代码补全 Prism.js 轻量级语法高亮库，支持 300+ 编程语言的代码着色 KaTeX 高速数学公式渲染引擎，支持 LaTeX 语法的实时预览 Mermaid 基于文本的图表绘制工具，支持流程图、时序图、甘特图等 Tauri 2 跨平台桌面应用框架，使用 Web 技术构建原生应用 @vscode/codicons VS Code 官方图标字体库，提供 600+ 专业级界面图标 ESLint 可配置的 JavaScript 代码检查工具，确保代码质量和规范 Prettier 固执己见的代码格式化工具，统一团队代码风格 Vitest 基于 Vite 的下一代单元测试框架，极速的测试执行体验
