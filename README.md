# Markdown 编辑器

一个现代化的 Markdown 编辑器，支持实时预览、代码高亮、图表渲染等功能。

## 功能特性

- ✨ 实时预览
- 🎨 深色/浅色主题
- 📝 代码高亮（Prism.js）
- 📊 Mermaid 图表
- 📑 自动目录生成
- 💾 本地文档管理
- 📤 导出 HTML/MD
- 🔍 可拖拽调整布局

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

访问 http://localhost:3000 开始使用。

## 技术栈

- **Vite** - 构建工具
- **Marked** - Markdown 解析
- **DOMPurify** - HTML 净化
- **Prism.js** - 代码高亮
- **Mermaid** - 图表渲染
- **KaTeX** - 数学公式
